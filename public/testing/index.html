Security & Role Isolation Suite

All 18 automated security attack tests pass with zero vulnerabilities.

  • Judge Isolation: An assigned judge attempting to query peer evaluations receives an explicit 403 Forbidden.
  • Participant Protection: Hackathon participants cannot access raw or unreleased judge scores.
  • Data Export Shielding: An unauthenticated visitor or participant attempting to trigger /api/export.csv receives 401 Unauthorized or 403 Forbidden.
  • Cross-Event Shielding: Organizers are isolated to their own events; cross-event workspace access is denied.
  • Rubric Integrity: Submitting invented criteria or unassigned project scores is strictly rejected.

Cloud Infrastructure & Deployment

Judgely is engineered for both 100% offline self-hosting and Firebase Cloud operation:

  • Self-Hosted Mode (Default): Pure SQLite, zero cloud dependencies, offline-first. Runs natively with Docker.
  • Firebase Hosting: Target judgely at https://judgely.web.app.
  • Firebase Firestore: Default database with compiled security rules (firestore.rules) enforcing zero-trust client access.
  • Firebase Authentication: Identity Toolkit configuration supporting Google Identity Services and session exchange.
