For organizers

Run your hackathon here.
Keep your data.

Hackerly is the whole event, not a form builder. Tracks, teams, submissions, judge invitations, weighted rubrics, judging progress, results and CSV export — with the rules enforced on the server and an audit trail for the operations that matter.

Create an account to host Sign in

Free and open source. Self-host it with one Docker command, or run it in the cloud.

What you get

  • Setup wizard that ends in a publishable event page
  • Your own branding: cover, accent colour, name, description
  • Tracks, team size rules, solo or team-only
  • Submission fields you define, validated server-side
  • Judge invitations by email, with acceptance tracking
  • Weighted rubrics; judges score against exactly what you published
  • Judging progress: who is behind, what is uncovered, what to chase
  • Results with documented normalization, or plain averages
  • CSV export of results, projects, teams, reviews, judges, audit
  • Audit log of every operation that changes the event

Two ways to run it

Local or global — the difference is the architecture, not the theme

Local

Local hackathon

For a physical event, a college fest, a company offsite. Self-contained: one process, one SQLite file, no internet required once the container is running.

  • Runs with the network off
  • Local accounts and sessions, no external identity provider
  • Invitations printed from the outbox instead of emailed
  • Export the database at the end and you own it
Global

Global hackathon

For a public event on the open internet. Public discovery, concurrent registration and submissions, a judging panel working in parallel, and a public showcase afterwards.

  • Public event listing and per-event microsites
  • Firestore-backed storage when deployed on Google Cloud
  • Paginated reads, caching, rate limiting, background-safe writes
  • Results published to a public page when you release them

Self-hosting

One command, no cloud account

docker compose up starts a fully working Hackerly on port 8080 with the schema created, the fixtures loaded and the demo event seeded. The database is a file on a volume. Nothing phones home. 

git clone https://github.com/your-org/hackerly
cd hackerly
docker compose up --build
