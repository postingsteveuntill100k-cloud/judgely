Invite a judge

One address per line, or separated by commas. Each gets its own single-use link.

How invitations work

The link creates a real user bound to your panel when they accept. It only works once, and only for the address it was sent to. If a judge already has a Hackerly account, the invitation attaches to it rather than creating a duplicate.

Mail mode: log. Without SMTP, invitations are written to data/outbox/ and shown here. The interface says which it is rather than claiming an email went out.
