Start from a preset

A repository, a demo, a tech list and one written answer is enough for most events. Add video only if you will actually watch it.

  • Source code (url, required)
  • Working demo (url)
  • Demo video (url)
  • Documentation (url)
  • Technologies used (tags, required)
  • What problem does it solve? (textarea, required)
  • How does it work? (textarea)
  • What did you try that did not work? (textarea)

What the server checks

Required fields are non-empty, links are https, and the team has a track if you have tracks. Failures come back as a list, not a single opaque error.
