Basics

Public URL: /hackathons/…

One line, under the title on the event page. Say what kind of hackathon this is.

At least 40 characters. This is the part a stranger reads before registering — write it for them.

Shown publicly unless you turn contact visibility off in settings.

What a good description does

  • Says who the event is for in the first sentence
  • Names the kind of thing worth building
  • States the dates and the prize, even if briefly
  • Says what happens after submissions close
  • Does not pretend to be an AI platform

Where this shows up

The event page, the discovery cards, the search index and the public API all read the same fields.
